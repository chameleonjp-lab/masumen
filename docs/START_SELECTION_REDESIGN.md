# 開始前選択要素の調査と再設計

更新日: 2026-08-29  
対象: Grid Signal Arena の開始前準備、戦闘中カード選択、カード候補50枚

## 結論

本作では、開始前の準備と戦闘中の選択を分ける。

1. 開始前: プレイヤーが30枚のフォルダを準備する。
2. 戦闘中: フォルダからランダムに提示された5枚のアクティブカードを選び、選択順に実行する。
3. 複数枚選択: 同名、同一カードコード、または共通コード（*）のカードだけを同じキューへ追加できる。
4. 恒常・受動スキル50種: 今回は採用しない。

既存の start_skill_candidates_50.md は発想を失わないために保存するが、採用仕様の一覧ではない。採用候補50枚は、現行コードのカードカタログにあるアクティブカードである。

この判断は、「原作に開始前要素がない」という意味ではない。原作には、戦闘中のカスタム画面とは別に、ナビカスタマイザーやレギュラーチップ容量のような戦闘前設定がある。ただし、それらを本作で50個の受動スキルへ置き換えることは、原作の再現ではなく追加設計になる。今回は戦闘の読み合いとカード選択を優先し、恒常設定の層を増やさない。

## 1. 資料から確認した事実

| 要素 | 確認内容 | 本作への扱い |
| --- | --- | --- |
| 戦闘中のカスタム画面 | フォルダから選ばれたチップがランダムに提示され、基本的に1枚を選ぶ。 | ランダム5枚のアクティブカードとして実装済み |
| 複数選択 | 同じ名前、または同じチップコードのチップを選ぶ場合に限り、最大5枚まで選べる。 | 同名・同コード・共通コード（*）のキュー制約として実装済み |
| 実行順 | 選んだチップは選択順に送られ、カスタムゲージが空になると実行される。 | 選択キューとゲージ処理で表現する |
| ナビカスタマイザー | 戦闘前に組む設定で、カスタム画面の提示枚数や能力などを変える部品がある。 | 本作では独立した50スキル層にせず、必要なら後続の小規模ロードアウトとして再検討する |
| レギュラーチップ | 戦闘前に指定する、毎回のカスタム画面へ優先的に出るチップ枠。 | 現行のフォルダ準備とは別機能。今回の必須実装には含めない |

原作のチップ選択条件は、[カプコン公式マニュアルの戦闘画面](https://game.capcom.com/manual/REXEAC/vol2/ja/ps4/page/1/2)を基準にした。チップの分類・コード・個別効果の照合には、[チップ一覧](https://game8.jp/rockman-exe-4/522098)、[通常チップ一覧](https://game8.jp/rockman-exe-4/522124)、[メガクラス一覧](https://game8.jp/rockman-exe-4/522125)を補助資料として使った。ナビカスタマイザーの存在とカスタム画面枚数への影響は、[ナビカスタマイザー一覧](https://game8.jp/rockman-exe-4/522393)および[カスタム1](https://game8.jp/rockman-exe-4/523567)で確認した。

## 2. 現行実装との差分

| 確認項目 | 現行状態 | 判定 |
| --- | --- | --- |
| 30枚フォルダ | FolderEditor と保存スロットがある | 継続 |
| カードカタログ50枚 | deck.ts と card_catalog_50.md にある | 継続 |
| 戦闘中のランダム5枚 | 実装済み | 継続 |
| 同名・同コード・共通コード（*）の選択制約 | 実装済み | 継続 |
| 50個の恒常・受動スキル | 未実装 | 実装しない |
| 敵攻撃の予兆表示 | 後続タスク | 次の実装優先候補 |

したがって、今回必要なのは新しいスキルシステムのコードではなく、開始前選択の仕様を確定し、既存カード50枚の役割と敵AIへの適用先を共通の表にすることである。

## 3. 旧50スキル案の扱い

旧案は、攻撃強化、移動補助、反撃、デッキ補助、スコア・無限戦向けの恒常効果を1枚の表に混在させていた。アイデアとしては有用だが、次の理由で採用仕様にはしない。

- 原作のカスタム画面で選ぶアクティブチップと、戦闘前に固定される恒常効果を一つの概念にまとめてしまう。
- 既存カード50枚の「選んだ瞬間に効果が出る」設計と、常時発動・条件発動の効果が競合する。
- 敵AIへの対抗手段が、カード選択ではなく事前の正解スキル選びに寄り、戦闘中の読み合いを弱める。
- 保存スロット、難易度、スコア、将来のアップグレード枠まで同時に仕様化するため、現在の戦闘実装から遠い。

## 4. 採用する再設計

### 4.1 開始前: フォルダ準備

- 30枚のカードをフォルダへ登録する。
- 保存スロットから使用フォルダを選ぶ。
- カードの系統、コード、同名・同コードのまとまりを確認する。
- 「開始前に選ぶもの」は、まずこのフォルダとする。

### 4.2 戦闘中: カスタム選択

- カスタムゲージが満ちると、使用フォルダから5枚を提示する。
- 0枚から最大5枚まで、状況に応じて選ぶ。
- 複数枚を続けて選ぶ場合は、同名、同一コード、または共通コード（*）のカードだけをキューへ積む。
- キューは選択順に処理し、実行時の対象・フォールバック・予兆をカードごとに解決する。

### 4.3 将来の恒常設定

ナビカスタマイザーのような事前ロードアウトを追加する場合も、最初から50個のランダムな受動スキルにはしない。まずは「提示枚数」「ゲージ速度」「レギュラーカード」のように役割が重ならない少数の設定へ分け、戦闘の検証後に必要性を判断する。

## 6. 実装と検証の境界

この整理で追加するのは仕様書と参照表であり、恒常スキルのコードではない。次の実装では、カード実行前に敵攻撃の予兆を見せ、プレイヤーが上表のカードを選ぶ判断時間を作る。

検証時は次を確認する。

- 30枚フォルダのカードがランダム5枚へ正しく反映される。
- 同名・同コード・共通コード（*）以外のカードが同じキューへ混ざらない。
- カードの対象不在時に、カードごとのフォールバックが一貫している。
- 遅延・設置・反撃カードが、敵攻撃の予兆と同時に読める。
- 表の「主な適用先」が、敵AIの行動パターンと実際に噛み合う。
