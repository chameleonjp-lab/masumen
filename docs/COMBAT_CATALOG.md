# 戦闘カタログ基準表

このファイルは、戦闘再構築のPR1で現行コードを保護するための基準表である。カード名や敵名を変更する場合は、先に`COMBAT_REBUILD_PLAN.md`とこの表を更新し、監査を通す。

## 現行カードカタログ

現行の`client/src/game/deck.ts`は、標準46枚・上位相当4枚の合計50枚を定義する。最終仕様では、カタログ50枚を最初から利用可能とし、戦闘中に使うフォルダは30枚へ分離する。

| 分類       | 現行ID                                                                        |
| ---------- | ----------------------------------------------------------------------------- |
| 射撃・範囲 | `rapid`, `lance`, `seeker`, `triplet`, `wide`, `column`, `cross`, `fan`       |
| 属性       | `ember`, `fireline`, `frost`, `icewall`, `volt`, `thunderline`, `root`, `web` |
| 近接       | `slash`, `sweep`, `dashslash`, `gridcut`, `moonblade`                         |
| 設置       | `timer`, `watchmine`, `turret`, `stake`, `breakpillar`, `block`, `toxic`      |
| 地形       | `sanctum`, `crack`, `rush`, `sector`, `gravity`, `gustwall`, `hole`           |
| 防御・反撃 | `prism`, `phase`, `return`, `substitute`, `magguard`, `premonition`           |
| 回復・補助 | `rectify`, `repair`, `fastsync`, `stamp`, `reroute`                           |
| 上位相当   | `meteor`, `dream`, `sanctuary`, `overdrive`                                   |

現行カタログの各IDは、描写レシピ、音響レシピ、シーン内の描画分岐を持つことをPR1の基準とする。攻撃判定が同じ範囲へ集約されている点は後続PRで解消する。

## 過負荷カード

過負荷カードはフォルダへ入れず、動揺中は40％、侵食中は100％の確率で通常手札1枚と入れ替える。接続コードは`!`で、他カードとは同時選択できない。

| カード   | 効果                                             | 個別の不利益                         |
| -------- | ------------------------------------------------ | ------------------------------------ |
| 限界砲   | 失ったHPに応じて最大400の直進ダメージ            | そのWave中、通常射撃威力半減         |
| 汚染拡散 | 着弾地点周囲3×3へ320ダメージ                     | 移動後の自陣パネルが毒化             |
| 強制修復 | HPを最大まで回復                                 | そのWave中、毎秒1HP減少              |
| 崩落領域 | 敵陣を毒化し、自陣の現在地以外を一時的に穴へ変更 | 次の手札表示数が1枚減る              |
| 断絶刃   | 敵へ踏み込んで400剣ダメージ                      | そのプレイ中、ゲージ上昇速度20％低下 |

過負荷使用時は侵食値を1増やし、最大HPを10、回復量を侵食値1につき10％、スコアを1回400減らす。侵食値はプレイ終了時に破棄する。

## 最終カード分類

| クラス | フォルダ制限                                            |
| ------ | ------------------------------------------------------- |
| 標準   | 同名はコード違いを含めて最大4枚                         |
| 上位   | フォルダ内合計5枚。同名は1枚まで                        |
| 切札   | フォルダ内合計1枚                                       |
| 過負荷 | フォルダへ入れない。動揺・侵食時の手札へ最大1枚だけ出す |

接続コードはA〜Fと共通コード`*`を使う。選択済みカード全体が同名、同一コード、通常コードと`*`、または`*`だけの場合だけ送信できる。

## PR1の保護対象

- カードカタログ50枚
- 既存の敵5系統（BULWARK-3、SCANNER-8、RAZOR-6、MORTAR-NODE、VOLT-SENTINEL）
- 4Waveの開始・カード選択・戦闘・Wave間・結果の遷移
- 既存のカード描写・音響監査
- ローカル最高記録の読み書き

ここで確認するのは「現行が存在し、再現できること」であり、最終仕様への置き換え完了を意味しない。
